# WaferLog 硅笺

> 随手一笔，久久有回响。

WaferLog 硅笺是一套「会回来的笔记」：一台只能写字的便携终端 + 一个替你保管记忆的云端档案馆。

- **在设备上**，你永远只面对一张空白纸——手写、录音，开机即写，没有通知，没有红点。横过来，它就是桌上的日历。（记录终端基于涂鸦 T5AI 开发板打造，固件项目见仓库根目录 `README.md`。）
- **回到云端**，写过的每一页都被好好收着。某天你再提笔，过去的相关笔记会像底片显影一样浮出来，每一条都告诉你「为什么是它」，都能点回原稿。

本仓库是云端与 Web 端的可运行原型：无需硬件，即可演示从记录到回响的完整闭环。

## 定位与场景

**一句话定位：我们不和手机 / iPad 竞争「记」，我们解决「想起」。** 备忘录、GoodNotes、flomo 们已经把「写下来」做到极致，但记完即坟场——WaferLog 做的是闭环的后半程：设备端负责无打扰地记下来，云端负责让过去的记录在恰当时刻自己回来，并说得清为什么回来。

### 它解决什么——三个真实的瞬间

1. 出门在外，灵感一闪——没带本子；掏出手机，先看到三条未读消息，灵感没了。
2. 开完一场会——录音躺在手机里，你知道自己再也不会花一小时去整理它。
3. 记了三年笔记——要用的时候，一条也想不起来它存在过。

### 给谁

随时在记、又总是找不回的人：上课要记、实验要记的学生和研发工程师，会议一场接一场的办公人群。不是他们懒，是工具错了——手机太吵，纸笔太「死」，智能记事本太贵太封闭。

### 三个场景

1. **长线灵感**：6 月写「通知为什么会打断思考」，7 月写「想做一个减少打扰的设备」——旧笔记自己浮出来，想法接上了，而不是从零重想。
2. **会议**：设备录音 + 随手两笔要点，回去时纪要已经写好，待办等你确认进日历。
3. **复习与写作**：问「我以前为什么认为低干扰重要？」——答案来自你自己的档案，带着出处。

### 为什么不用手机或 iPad

- 手机是干扰源；iPad 笔记为「正式笔记」设计——选模板、建笔记本、排版。WaferLog 针对中间地带的碎片：不值得打开 App、但丢掉可惜的那些。
- 搜索要求你记得它存在；回响不需要。
- 别家 AI 替你做主——自动摘要、自动归类、出处不明；我们原稿优先、结论带来源、行动需确认。
- 市面智能记事本贵且封闭；我们做开放的、买得起的。

**诚实的边界**：只为「记」，手机就够。WaferLog 的价值在积累两三周后开始涌现——回响密度随笔记数增长。这也是演示档案预置 52 天数据的原因：模拟产品开始兑现价值的那个时刻。

## 作品详细描述

### 我们怎么做

**先记录，后整理；原稿优先；一切结论可溯源。**

- **落笔即存**：打开就是一张空白纸，手写（压感笔迹）、文字、语音三种方式，1 次点击即达，自动保存，保存时纸面泛起一圈落笔波纹。
- **回响，而不是推荐**：每写一页，系统在后台把它与旧笔记关联。首页「记忆回路」把回响呈现在琥珀色的记忆底片上——不是信息流，最多两张回响票据，每张都带一句人话依据：「同属『产品设计』，都提到『设备』、『干扰』，相隔 25 天」。没有关联时，诚实地说「这页正在等待新的连接」。
- **溯源，而不是黑箱**：单页详情左侧永远是原稿（手写笔迹原样回放），右侧是一层可揭开的「注释膜」：OCR 文字层（可编辑，AI 只读不写）、主题、关联列表、待办候选。AI 的每个结论都能点回来源纸页。
- **问答，而不是编造**：知识问答只面向「我的档案」。回答呈一张「档案检索结果单」：结论在上，来源纸页卡在下。档案里没有依据时，它明说「档案中没有足够依据」，绝不编造。
- **确认，而不是代劳**：从记录里识别出的行动项只是「候选」，安静地躺在时间册右侧，等你一键加入 / 改期 / 稍后 / 忽略——确认之后才会进入日历。

### 产品链路

```text
设备端：手写采集 / 录音采集 / 本地保存（本地优先，断网可用）
   ↓ Wi-Fi 上传
服务器：语音转写 / 手写识别 / 内容总结 / 知识点提取 / Idea 扩展 / 笔记关联计算
   ↓ 同步回设备与 Web
Web 端：回响票据 / 原稿溯源 / 知识问答 / 待办确认入日历
```

### 创新点

1. **一体化低成本终端**：手写、录音、日历与 AI 知识整理集成在一台开放的便携设备中——对比高价封闭的智能记事本，成本低、可自定义。
2. **手写即数据**：手写内容不只是保存为图片——笔迹可原样回放，同时经识别成为可检索、可关联的知识数据。
3. **可溯源的知识关联**：自动发现不同笔记之间的联系，且每条关联都带人话依据、可点回原稿——不是黑箱知识图谱。
4. **本地优先 + 离线兜底**：断网时设备仍可手写、录音与保存；没有网络、没有大模型，云端也能演示完整流程。

### 页面

| 页面 | 职责 |
| --- | --- |
| 档案馆（首页） | 刚刚落笔的纸页 + 记忆回路上的回响票据 + 还在生长的纸页 |
| 记录编辑器 | 手写画布（压感/橡皮/撤销）/ 文字 / 语音，自动保存；同时模拟设备端记录体验 |
| 所有记录 | 档案抽屉式纸页网格，按月分组，搜索与筛选，回收站 |
| 单页详情 | 原稿 + 注释膜（文字层 / 关联 / 待办），就此页提问 |
| 主题盒 | 档案盒隐喻，改名、合并、移出，一条记录可多主题 |
| 记忆线 | 一个想法如何逐步形成：3–5 个节点，节点间一句「为什么连上」 |

### 视觉语言：记忆显影仪

纸白底、墨色正文、半透明琥珀时间层。原稿用手写体，永远比 AI 层更醒目；回响回路用暖琥珀微光，只在强关联时生长一次；不用科技蓝，不做 SaaS 侧栏后台感，不做等宽卡片海。支持暗色「墨夜」主题、`prefers-reduced-motion`、移动端单手操作（≤600px 底部导航，热区 ≥44px）。

## 技术栈

- **整体架构**：设备端固件（Tuya T5AI-Board + T5-E1-IPEX 触控屏，LVGL 界面，C / CMake，Windows SDL2 模拟器，硬件能力经 `hal/waferlog_services.*` 服务层抽象，见 `README1.md`）→ Wi-Fi 上传 → 本仓库服务器（接收 / 转写 / 分析 / 关系计算）→ 同步回设备与 Web 端展示。AI 模型规划为 Qwen2.5-VL-72B 多模态大模型 + ASR 语音转写；兼容 OpenAI 端点，用户可自建 baseurl。
- **前端**：React 18 + TypeScript + Vite + React Router。手写画布用 [perfect-freehand](https://github.com/steveruizok/perfect-freehand)（压感平滑笔迹，笔画存为点数组 JSON，分辨率无关、可原样回放）。无 UI 框架——纯现代 CSS：设计令牌（custom properties）+ Grid/Flex + `clamp()` 流体排版，标志性动效（回响细线生长、落笔波纹）手写 SVG/CSS 实现。
- **后端**：Node + Express + `node:sqlite`（Node 内置 SQLite，零原生依赖，开箱即跑）。REST API：`/api/notes` `/api/topics` `/api/relations` `/api/tasks` `/api/ask` `/api/calendar` `/api/export`。
- **AI 层（可插拔 Provider 模式）**：配置 OpenAI 兼容端点即可走 LLM；未配置时规则引擎兜底，全程离线可演示——
  - 关联：领域词表 + CJK 二元组切分，加权余弦相似度 × 主题 × 时间衰减打分，分数与证据词共同生成「人话依据」；
  - 问答：抽取式回答，必须携带 `sourceIds`，无依据时明确拒答；
  - 待办：动作词正则 + 中文日期解析（今天/明天/下周三/M月D日/月底）。
- **工程**：npm workspaces（`server/` + `web/`），根目录一条命令同起前后端；13 项 API 冒烟测试覆盖完整演示闭环。

## 一键启动

```bash
# 环境要求：Node.js ≥ 22（推荐 24，内置 SQLite 开箱可用）
npm install
npm run dev
```

- 前端 <http://localhost:5173>（Vite 代理 `/api` → :2001）
- 首次启动自动注入 12 页示例档案（覆盖 产品设计 / 低干扰 / 知识管理 等主题），开箱即演
- 重新注入演示数据：`npm run seed -- --force`
- API 冒烟测试（13 项）：先启动服务，再运行 `npm run smoke`
- 生产模式：Node 服务在 `:3737` 同时提供 Web 和 API；设置 `COMPAT_PORT=80` 后，可兼容现有 T5AI-Board 的 `80` 端口上传请求。

## 演示脚本（约 3 分钟）

1. **落笔**：点「落笔」，随手写一页——比如「想做一个减少通知打扰的设备」。落笔即存，纸面泛起波纹。
2. **回响**：回到档案馆，「记忆回路」显示「N 条回响正在形成」，两张回响票据各带一句人话依据。
3. **溯源**：点开一张票据，跳到 6 月写下的旧笔记；左侧原稿、右侧关联依据，再点「记忆线」看这个想法如何逐步形成。
4. **问答**：到知识问答，问「我以前为什么认为低干扰输入重要？」——结论在上，三张来源纸页卡在下，点卡片跳回原稿。
5. **待办**：打开时间册，右侧「待确认」里躺着几页记录里识别出的行动项，点「一键加入」，它带着 ● 出现在日历上。
6. **诚实**：问一个档案里没有的问题，比如「我对量子计算怎么看？」——它明说「档案中没有足够依据」，不编造。
7. **移动端**：把手机宽度缩到 375px，底部导航单手可走完全部流程。

```
handoff/
├── package.json          # npm workspaces，一键启动
├── server/               # Express + node:sqlite
│   ├── src/
│   │   ├── index.js      # 入口：静态托管 + SPA 回退 + 首启注入示例

│   │   ├── ai.js         # 规则 AI 层：关联 / 问答 / 待办（可换 LLM Provider）
│   │   ├── service.js    # 关联重算、待办抽取、业务编排

│   └── scripts/smoke.mjs # 13 项 API 冒烟测试
├── web/                  # React + TS + Vite
│   └── src/
│       ├── components/   # PaperPage（笔迹回放）、Nav、Icon…
│       ├── pages/        # 9 个页面 + 记录编辑器

└── assets/shots/         # 16:9 封面与轮播截图
```
