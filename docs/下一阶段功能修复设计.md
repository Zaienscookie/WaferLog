# WaferLog | 硅笺

## 本轮目标

本轮先修复 Windows LVGL 模拟器中的交互和显示问题，再继续移植到 Tuya T5AI-Board。

当前阶段只使用本地模拟服务：

- 不连接开发板串口
- 不调用真实 Wi-Fi 扫描
- 不调用真实蓝牙扫描
- 不加入音乐功能
- 不改变现有 AI 服务接口方向

## 当前问题

### 暗色模式

- 手写画布仍然使用白色背景。
- 横线、网格和点阵在暗色模式下对比度不合适。
- 部分卡片标题仍然使用深色文字，放在深色表面上时看不清。
- 日历 Hero、连接弹层和部分按钮需要统一适配暗色文字。

### 语言切换

当前语言按钮只改变顶部的语言代码，正文仍然保持英文。

语言切换后需要重新渲染以下内容：

- 首页
- 笔记页
- 日历页
- 语言弹层
- 外观弹层
- Wi-Fi / 蓝牙连接弹层
- 操作提示文字

保留品牌名称：

```text
硅笺 | WaferLog
```

计划支持：

- English
- 中文
- 日本語
- Français
- Русский

## 手写画布修复方案

### 事件状态

手写输入分成三个阶段：

```text
按下 PRESSED
    只记录起点，不绘制，不新增笔画

移动 PRESSING
    只有坐标确实发生变化时才新增笔画段

释放 RELEASED / PRESS_LOST
    清除当前笔画状态
```

这样可以避免按下瞬间产生一个异常的大圆点。

### 笔触宽度

当前伪压感逻辑会在按下时额外增加宽度，导致出现明显的大点。

调整为：

- 用户设置的笔宽作为基础宽度
- 慢速移动最多增加 1 到 2 像素
- 快速移动最多减少 1 像素
- 最小宽度为 1
- 最大宽度为 12
- 按下事件不产生独立笔画

### 坐标稳定

- 以画布实际坐标为基准计算触点。
- 每次事件都限制在画布边界内。
- 不在绘制过程中重建画布对象。
- 翻页、切换颜色、切换纸张时才重新绘制整页。
- 画布只使用一个 RGB565 缓冲区，页面内容使用笔画段记录。

### 深色画布

亮色模式：

```text
背景：#FFFFFF
纸张线：#DCE7ED
```

暗色模式：

```text
背景：#171B21
纸张线：#36404A
```

暗色模式下第一支笔使用浅色墨水，其他颜色保持蓝、红、绿的可读性。

橡皮擦使用当前画布背景色绘制，不使用固定白色。

## Wi-Fi / 蓝牙交互

### 入口

首页的 Wi-Fi 和蓝牙卡片不再直接切换状态，而是打开“连接”底部面板。

连接面板包含两个标签：

```text
Wi-Fi
Bluetooth
```

### Wi-Fi 面板

功能：

- 开启或关闭 Wi-Fi 模拟服务
- 搜索附近网络
- 显示网络名称
- 显示信号强度
- 显示是否加密
- 点击网络进行连接
- 添加隐藏网络
- 手动输入网络名称
- 手动输入密码
- 显示或隐藏密码
- 连接成功后显示当前网络
- 断开当前网络

模拟网络：

```text
WaferLog Lab     92%   加密
Tuya T5AI       78%   加密
Home Office     64%   加密
Demo Guest      47%   开放
```

连接规则：

- 加密网络需要输入密码。
- 开放网络允许空密码连接。
- 普通密码长度限制为 8 到 63 个字符。
- 64 位密码只允许十六进制字符。
- 网络名称为空时不能连接。

### 蓝牙面板

功能：

- 开启或关闭蓝牙模拟服务
- 搜索附近设备
- 显示设备名称
- 显示信号强度
- 点击设备进行连接或断开

模拟设备：

```text
T5AI Board       88%
WaferLog Pen     72%
Desk Controller  55%
```

## 服务接口方向

Windows 模拟器先使用以下抽象接口：

```c
bool waferlog_wifi_scan(void);
uint32_t waferlog_wifi_scan_count(void);
const char * waferlog_wifi_scan_ssid(uint32_t index);
int32_t waferlog_wifi_scan_signal(uint32_t index);
bool waferlog_wifi_scan_secured(uint32_t index);

bool waferlog_ble_scan(void);
uint32_t waferlog_ble_scan_count(void);
const char * waferlog_ble_scan_name(uint32_t index);
int32_t waferlog_ble_scan_signal(uint32_t index);
```

后续移植到 T5AI-Board 时，只替换服务层实现，UI 不直接依赖 TuyaOS 的底层 API。

T5AI-Board 的实际引脚、联网能力和蓝牙能力仍以当前 TuyaOS 工程及官方板卡资料为准，不在 Windows 模拟阶段假设具体 pinmux。

## 页面变化

### 首页

- Wi-Fi 卡片点击打开连接面板。
- Bluetooth 卡片点击打开连接面板。
- 连接成功后首页卡片显示当前名称。
- 底部状态条显示 Wi-Fi、蓝牙和云端上传状态。

### 笔记页

- 暗色主题下画布变为深色。
- 工具栏文字跟随语言变化。
- 纸张选项跟随语言变化。
- 保存、上传、清空和错误提示跟随语言变化。
- 手写过程不再因按下事件产生大点。

### 日历页

- 标题、议程和天气文字跟随语言变化。
- 暗色模式下 Hero、月历和日期文字保持清晰。

### 设置弹层

- 语言弹层选择后立即刷新所有页面文字。
- 外观弹层切换亮色/暗色后保留当前页面和笔记内容。
- 主题色切换后保留当前页面和笔记内容。
- 连接弹层和密码输入弹层使用相同的主题颜色。
